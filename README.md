# Amor por Patinhas

Demonstração de site para banho e tosa na Vila Carrão. React, TypeScript e Vite.

`npm ci` instala as dependências. `npm run check` verifica os tipos e `npm run build` gera o site em `dist`.

Os dados públicos ficam em `src/loja.ts`. Na Vercel, o endereço de produção é detectado no build. Defina `VITE_SITE_URL` para usar outro endereço canônico.
